# Onboard Lite

一个轻量版的罗技 G 鼠标板载内存设置工具，用来替代 Logitech OnboardMemoryManager（OMM）。

> **English:** A tiny (~200 KB) open-source alternative to Logitech's Onboard Memory Manager for Logitech G mice. It edits the mouse's onboard profiles (DPI stages, report rate, button mapping, lighting, profile names) over HID++ 2.0, with no G HUB or installer required. Windows 10/11, .NET Framework 4.8 (built in). The UI is available in Chinese and English.

## 下载

到 [Releases](../../releases) 下载最新的 `OnboardLite-vX.Y.Z.zip`，解压后直接运行 `OnboardLite.exe`。

程序没有代码签名，第一次运行时 Windows SmartScreen 可能会拦截，点"更多信息 → 仍要运行"即可。

- 单个 exe，约 200 KB（OMM 是 12.7 MB），不需要安装，也不需要 G HUB
- 依赖 Windows 10/11 自带的 .NET Framework 4.8，直接用系统里的 `csc.exe` 编译
- 设置写进鼠标自己的板载内存，换电脑、不开任何软件也会生效

## 功能

- **多设备**：首页"我的设备"会给每台设备显示一张卡片，包括在线、休眠中和暂不支持的设备。同一只鼠标同时插着线和接收器时，只显示一张卡片。
- **二级页面**：点进某台设备后，左侧菜单可以切换以下几页：
  - **性能**：DPI 最多 5 档，可以设默认档和 DPI Shift 档；滑杆按对数刻度移动，也可以直接输入数值。回报率只列出设备支持的档位。另有角度捕捉开关。
  - **按键**：可以映射为鼠标按键、DPI 或配置功能、媒体键、任意键盘组合键，或者禁用。
  - **灯光**：仅在有灯的设备上显示。可选关闭、常亮、呼吸、色彩循环四种效果，配有颜色、速度和亮度调节，并带实时动画预览。和 OMM 一样，每套配置只设一种灯效，作用于设备的所有灯区；用 0x8071 灯光协议的设备，省电时会自动改用一半亮度的同款灯效。
  - **配置管理**：管理 5 个板载配置，可以改名、启用或停用、立即切换使用、恢复出厂设置。
  - **设备信息**：连接方式、固件版本、序列号、电量、工作模式、板载内存格式，以及打开备份文件夹的入口。
- 修改后底部会出现保存栏，列出哪些配置还没保存。每台设备的修改相互独立。
- **亮色 / 暗色主题**：右上角按钮切换，切换时整个界面约 0.4 秒平滑淡入淡出，不会突然一闪。第一次打开时跟随 Windows 设置，之后记住你的选择。
- **中 / 英文**：右上角的"文 | ENG"开关一键切换，界面立即更新。第一次打开时跟随 Windows 的显示语言。主题和语言都保存在 `%AppData%\OnboardLite\settings.ini`。
- **热插拔**：程序监听 Windows 的设备插拔消息，插上或拔掉接收器、数据线后会立即重新扫描，不需要手动点"重新扫描"。鼠标休眠后也会自动重新连接。
- 快捷键：`Ctrl+S` 保存，`F5` 重新扫描。

## 安全措施

- 每次会话第一次写入前，先把原来的扇区备份到 `%AppData%\OnboardLite\backups\<设备>-<序列号>\<时间>\`
- 每个扇区写完都会读回来逐字节比对
- 不写 ROM 区（扇区号 ≥ 0x100）
- 每个配置里至少要有一个键保留为左键
- 只编辑已经核实过的配置格式 1–5，遇到其他格式会拒绝读写

## 已测试的设备

- **Logitech G PRO X SUPERLIGHT**（配置格式 4），有线和 LIGHTSPEED 无线都测过：读取、保存、热插拔均已在实机上验证。
- **灯光功能还没有在带灯的设备上实测过。** 数据格式是按 OMM 的实现做的，离线测试也都通过了，但如果你有带 RGB 的罗技 G 鼠标，欢迎反馈结果。程序在第一次保存前会自动备份原配置。

## 实现依据

对 OnboardMemoryManager 2.5.358 的逆向分析（按 REA 方法：识别目标 → 摘要优先 → 基于证据），得到以下结论：

- OMM 是 .NET Framework 4 的 WPF 程序（使用 MahApps.Metro）。它的 12.7 MB 里，大部分是嵌入的 VC++ 运行库、.NET facade 程序集和 21 个语言包
- 真正负责和设备通信的是嵌入的 `logi_nethidppio.dll`，这是一个 C++/CLI 写的 HID++ 2.0 库
- 配置扇区里各字段的偏移，是在 `logi_nethidppio.dll` 的原生代码中找到的（`profile_memory_manager` 会按配置格式构建组件表，入口在 RVA 0xe37a0 / 0xe3a8f / 0xe3c7f），之后在真实设备上读出扇区并逐项核对过
- 0x8100 写入命令的参数顺序，另外和开源的 libratbag 交叉核对过

### 配置扇区布局（格式 1–5）

| 偏移 | 内容 |
|---|---|
| 0x00 | 回报率（毫秒） |
| 0x01 / 0x02 | 默认 DPI 档 / DPI Shift 档的索引 |
| 0x03–0x0C | DPI 表，5 个 u16，小端 |
| 0x11 | 角度捕捉 |
| 0x20–0x5F | 16 个按键绑定，每个 4 字节 |
| 0x60–0x9F | G-Shift 层 |
| 0xA0–0xCF | 名称，24 个 UTF-16LE 字符 |
| 末尾 2 字节 | CRC-CCITT（初值 0xFFFF），大端 |

### 灯光（每个灯区 11 字节：1 字节效果号 + 10 字节参数）

| 偏移 | 内容 |
|---|---|
| 0xD0 / 0xDB | 灯区 0 / 1（0x8070 协议的 Logo / 侧边，或 0x8071 协议的灯区 0 / 1） |
| 0xE6 / 0xF1 | 0x8071 协议设备在省电时使用的副本 |
| 0xFC | 0x8071 协议的灯光标志 |

| 效果号 | 参数 |
|---|---|
| 1 常亮 | p[0..2] 为 RGB，p[3] = 2（无动画） |
| 3 色彩循环 | p[5..6] 为周期（毫秒，高位在前），p[7] 为亮度 |
| 10 呼吸 | p[0..2] 为 RGB，p[3..4] 为周期，p[5] 为波形，p[6] 为亮度 |

### 按键绑定（4 字节）

| 编码 | 含义 |
|---|---|
| `80 01 hi lo` | 鼠标按键位掩码 |
| `80 02 mod key` | 键盘按键：修饰键 + HID 键码 |
| `80 03 hi lo` | 媒体键（Consumer 用法码） |
| `90 op 00 00` | 功能键（`op` 是 OMM 里的 FUNCTION_OPCODES） |
| `00 …` | 宏（本工具原样保留，不修改） |

`debug/` 里是调试用的小工具：离线自检（用真实扇区数据校验解析和 CRC）、设备发现测试、走同一套保存流程的命令行改回报率工具，以及几个不抢焦点的离屏测试：各页面在不同主题和语言下的截图、主题淡入淡出、插拔消息。把环境变量 `OBL_LOG` 设成一个文件路径，可以输出诊断日志。
